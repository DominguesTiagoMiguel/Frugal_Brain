# Direct Lake

## Evaluation Criteria
Use Direct Lake when:
- Data resides in OneLake.
- Near-real-time consumption is required.
- Model size supports the use case.

## Evaluate Against
- Import Mode.
- Direct Query.
- Operational complexity.
- Performance requirements.
