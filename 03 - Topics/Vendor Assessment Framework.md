# Vendor Assessment Framework

## Evaluation Dimensions
- Delivery capability.
- Technical quality.
- Governance alignment.
- Sustainability.
- Adoption enablement.
- Continuous value realization.
- Operationalization approach.
- Risk profile.

## Red Flags
- One-off project mentality.
- Limited knowledge transfer.
- Lack of measurable outcomes.
- Poor governance integration.
